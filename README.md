# FarisTRPL5BMobileApplication
 Mobile Application by Faris TRPL 5B

 Pada Halaman Home Terdapat 3 Button
(Change Button Color, Navigate to About, dan Navigate to Help)

1. Button Change Button Color : Saat diklik, terjadi perubahan pada warna button secara acak, contoh nya disini saya menggunakan default warna nya adalah hitam, jika diklik button tersebut akan berubah warna contohnya menjadi biru.
  
![HomeActivity](https://github.com/MohammadFarisF/Faris-TRPL5B-Mobile-Application/blob/add-networking-features-/app/src/main/res/drawable/homeactivity.jpg)

2. Button Navigate to About : Berisi Nama Aplikasi (Faris JBB APP), versi aplikasi (Versi 1.0), dan juga penjelasan singkat tentang aplikasi tersebut.

 ![AboutActivity](https://github.com/MohammadFarisF/Faris-TRPL5B-Mobile-Application/blob/add-networking-features-/app/src/main/res/drawable/aboutactivity.jpg)  

3. Button Navigate to Help : Berisi FAQ (Frequently Asked Question) tentang aplikasi tersebut, seperti aplikasi apa itu Faris JBB App, dan terdapat pertanyaan lainnya.

![HelpActivity](https://github.com/MohammadFarisF/Faris-TRPL5B-Mobile-Application/blob/add-networking-features-/app/src/main/res/drawable/helpactivity.jpg)

4. Button Navigate to Jokes : Berisi Fungsi utama dari aplikasi tersebut yaitu Jokes yang dapat di generate secara random, jokes berasal dari API.

![JokesDefault](https://github.com/MohammadFarisF/Faris-TRPL5B-Mobile-Application/blob/add-networking-features-/app/src/main/res/drawable/jokesdefault.jpg) ![JokesGenerate](https://github.com/MohammadFarisF/Faris-TRPL5B-Mobile-Application/blob/add-networking-features-/app/src/main/res/drawable/jokesgenerate.jpg) 

Conclusion : Saat Button "Change Button Color" ditekan maka akan terjadi perubahan warna pada button, Ketika Button "Navigate to Jokes" diklik maka akan diarahkan ke halaman Generator Jokesnya dan untuk mendapatkan jokes nya maka diharuskan untuk klik button "Generate Joke" untuk mendapatkan jokes - jokes secara random, Ketika Button "Navigate to About" diklik maka akan diarahkan ke halaman About, Ketika Button "Navigate to Help" diklik maka akan diarahkan ke halaman help, dan jika kembali ke "Home" maka warna yang diawal sudah diubah tidak kembali ke default tetapi tetap di warna yang sudah berubah.
